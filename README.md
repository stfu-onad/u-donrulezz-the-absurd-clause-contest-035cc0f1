One line, 200 characters at most: an absurd clause hidden deep inside a
terms-of-service agreement.

`main.py` writes a single original English sentence to `/output/entry.txt`:

> By using this service, you consent to your reflection being replaced in
> mirrors by a slightly more confident version of yourself on weekdays.

141 characters, one sentence, fully deterministic — no input, no randomness,
no network.
